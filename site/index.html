Accountable handoffs for door events and shared spaces

Smart doorbells alert everyone at once, creating diffusion of responsibility. Doorway Relay turns doorbell presses and motion triggers into accountable, assignable handoffs with explicit state progression and SQLite audit trails.

⚠️ The Problem: Alert Fatigue & Inaction

In family homes, co-living buildings, or elder care settings, an entrance notification buzzes every phone. Everyone assumes someone else handled it. Deliveries sit unattended on porches, visitors wait, and critical door events go unacknowledged.

✅ The Solution: Accountable Handoffs

Door events flow into a unified, neutral triage inbox. Team members explicitly claim tasks, assign owners, acknowledge receipt, and resolve issues with mandatory notes. State is strictly tracked from new to assigned, acknowledged, and resolved.

Judge Run-Locally Guide

Run Doorway Relay locally in under 3 minutes with pre-seeded demo credentials and our local event simulator.

1. Clone & Install Dependencies

Requires Node.js 22 (v22.12–v22.x) and npm 10+:

git clone https://github.com/ShoryaPratapSinghChandrawat/doorway-relay.git
cd doorway-relay
npm ci --ignore-scripts

2. Configure Local Environment

# Windows PowerShell:
Copy-Item .env.example .env

# macOS / Linux:
cp .env.example .env

Generate random keys for SESSION_SECRET, TOKEN_ENCRYPTION_KEY, and RING_SIMULATOR_HMAC_KEY with node -p "require('node:crypto').randomBytes(32).toString('hex')" and set a DEMO_PASSWORD of at least 12 characters.

3. Initialize SQLite & Seed Demo Items

npm run db:migrate
npm run seed:demo

4. Start Application

npm run dev

Open http://localhost:5173 and log in as demo@doorway.local with your configured password.
